## Задача 1.4

### Текст задачи
Метод `SubtractKopeks` (Вычитание копеек (`unsigned int`) из объекта типа `Money` с учетом того, что денежная величина не может быть меньше 0. Результат должен быть типа `Money`).

### Алгоритм решения
Сначала перевожу текущую сумму объекта в общее количество копеек (`rubles_ * 100 + kopeks_`). Дальше проверяю: если копеек для вычитания больше, чем есть у объекта, то возвращаю новый объект `Money(0, 0)` (чтобы не уйти в минус). Если всё нормально, вычитаю и возвращаю новый объект `Money`, созданный из получившегося общего числа копеек. В `main` тестирую этот метод с вводом данных с клавиатуры.

## Задача 2.1

### Текст задачи
Унарные операции: `--` вычитание копейки из объекта типа `Money`; `++` добавление копейки к объекту типа `Money`. (Реализовать префиксные и постфиксные версии).

### Алгоритм решения
Перегрузил операторы `++` и `--` (и префиксные, и постфиксные). 
Для `++` всё просто: добавляю 1 копейку и вызываю `Normalize()`.
Для `--` написал логику с проверками: если сумма равна нулю, ничего не меняю. Если копейки равны 00, то "занимаю" рубль (уменьшаю рубли и ставлю 99 копеек). Иначе просто вычитаю 1 копейку.
Постфиксные версии (`m++`, `m--`) сохраняют копию текущего объекта, меняют текущий и возвращают сохраненную копию. В `main` показал работу всех вариантов и проверил декремент нуля.

Для `bool` возвращаю результат проверки `(rubles_ != 0 || kopeks_ != 0)`.
В `main` проверил явное приведение через `static_cast<unsigned int>` и неявное — просто сунув объект в `if`. Нулевой объект должен давать `false`.

## Задача 2.3

### Текст задачи
Бинарные операции:
*   `-` (беззнаковое целое число) - число обозначает копейки;
*   `-` (`Money`) - вычитание денежных сумм.

### Алгоритм решения
Перегрузил оператор `-` двумя способами.
Первый принимает `unsigned int` (копейки). Тут просто вызываю метод `SubtractKopeks`.
Второй принимает другой объект `Money`. Перевожу оба объекта в общее количество копеек. Если вычитаемое больше исходного, возвращаю нули. Иначе вычитаю и возвращаю новый объект `Money` от получившейся разности. В `main` проверил оба варианта и случай, когда вычитаем больше, чем есть.
